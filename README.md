# FreeNodePick 精选节点订阅

只聚合 **6 个为墙内用户维护的精选节点源**，自动去重后生成 **Clash（带分类分流规则）** 与 **v2ray** 两种订阅，部署在 Cloudflare 上免费用、免服务器。

内置的 6 个源（2026-11-04 逐个实拉核验）：

| 源 | 说明 |
|---|---|
| end-gfw 免费节点（大翻墙运动） | 人工维护的公益订阅，节点少而精 |
| ChromeGo/EdgeGo 节点池 | 翻墙工具包的官方节点池（Misaka 合并版） |
| ermaozi 可达节点 | 只收它自己筛过的 reachable 可达名单 |
| 周润发公益节点 | shaoyouvip/free 每日更新的公益节点 |
| ripaojiedian 永久免费 | 主打永久免费的订阅池 |
| FreeNodeBiz 精选 | 持续更新的精选站公开名单 |

## 订阅链接规则（本项目的核心）

链接长这样：`/sub/clash-20261104-a1b2c3d4e5f6`

- **带日期**：中间的 `20261104` 是生成日期，一眼能认出是哪天的链接；
- **带密钥**：最后一段是随机密钥。打开面板点 **「🔄 生成新链接」**，会立刻换一把新密钥生成新链接，**旧链接随即失效（404）**——链接泄露了、或者想换一批，点一下就行；
- 前提：部署时要给它**绑定一个 KV**（下面教程里有，就多 3 步）。没绑 KV 也能用，但降级为「链接只在生成当天有效，隔天自动失效」。

另外可选设一个环境变量 `GEN_KEY`（管理口令）：设了之后，点「生成新链接」要先输入口令，防止别人打开你的面板乱点作废你的链接。

**每次订阅给出的节点数固定在 36~88 个之间**：池子大时取 88 个（Clash 与 v2ray 给同一批）；池子临时不足 36 个时，会自动去抓各源的备用地址补到达标，实在补不满才按实际数量给出。

**订阅里的节点都经过筛选，不是抓到什么就给什么**：

1. **真测活优先**：配套一条自有测活流水线（GitHub Actions 每 2 小时用 mihomo 把全部候选节点逐个真实连接测一遍，只留下当时测通的，并按实测延迟排序）。订阅选节点时，池中凡是上了最新测活名单的，一律优先入选并排在最前；
2. **来源信任序补位**：剩下的名额按来源可信度补（end-gfw 人工维护最优先，其次是 ermaozi 的可达名单、ChromeGo/EdgeGo 官方池等）；
3. **杂质剔除**：名称带推广字样（官网、订阅地址、机场推荐等）的条目直接剔除；同一台服务器最多入选 4 个，防止单个公共服务器扎堆。

面板上会实时显示本轮池中命中测活名单的个数与实际入选个数。

## 部署方式一：Cloudflare Workers（粘贴代码，约 2 分钟）

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) → 左侧「计算 (Workers)」→「Workers 和 Pages」→「创建」→「Worker」→ 随便起个名 →「部署」。
2. 点「编辑代码」，把编辑器里的内容全部删掉，把本项目 `workers/worker.js` 的全部内容粘贴进去 → 右上角「部署」。
3. 绑 KV（启用链接轮换）：左侧「存储和数据库」→「KV」→「创建命名空间」，名字随便（如 `freenodepick`）→ 回到你的 Worker →「设置」→「绑定」→「添加」→「KV 命名空间」→ 变量名填 **`SUB_KV`** → 选刚建的命名空间 →「部署」。
4. 打开 Worker 给的网址（`xxx.workers.dev`），看到面板即成功。

可选：Worker →「设置」→「变量和秘密」→ 添加变量 `GEN_KEY`，值设为你的管理口令。

## 部署方式二：Cloudflare Pages（上传文件，约 2 分钟）

1. 打开 [dash.cloudflare.com](https://dash.cloudflare.com) →「Workers 和 Pages」→「创建」→「Pages」→「上传资产」。
2. 项目名随便起 → 把本项目 `pages` 文件夹里的 `_worker.js` 上传（或把项目根目录的 `FreeNodePick.zip` 解压后上传里面的 `pages/_worker.js`，文件名必须是 `_worker.js`）→「部署网站」。
3. 绑 KV：进入这个 Pages 项目 →「设置」→「绑定」→「添加」→「KV 命名空间」→ 变量名 **`SUB_KV`** → 选一个命名空间（没有就先去「存储和数据库 → KV」建一个）→ 保存并重新部署一次（「部署」→ 最新一次部署右侧 `…` →「重试部署」）。
4. 打开 Pages 给的网址（`xxx.pages.dev`），看到面板即成功。

可选口令同上：在 Pages 项目「设置 → 环境变量」里加 `GEN_KEY`。

## 使用

1. 在面板下方下载并安装客户端（电脑 Clash Verge、安卓 FlClash / v2rayNG、iPhone 小火箭）；
2. 点面板里对应客户端的「一键导入」，或复制订阅链接到客户端里手动添加；
3. 在客户端里更新订阅，选「⚡ 自动选择」组或延迟最低的节点使用。Clash 订阅自带 ACL4SSR 式分类分流（国外流量 / Telegram / YouTube / Netflix 等 13 个分类组 + 国内直连、广告拦截）。

## 说明与边界

- 数据每约 10 分钟在 Cloudflare 边缘刷新一次，6 个源并行抓取、跨源去重；某个源临时挂了不影响其他源，面板里能看到每个源的实时状态。
- 本项目**不在 Cloudflare 上测活**（Workers 做不了逐个连接测试），节点的筛选由这 6 个源自己完成；免费节点寿命短，某个连不上时在客户端里换一个即可。
- 仅供学习测试，请勿用免费节点登录重要账号或传输敏感信息，请遵守当地法律法规。
